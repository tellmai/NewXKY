# NewXKY 区域答题助手

Windows 本地桌面程序。参考 Answering-S 的 PDF 题库解析、本地 OCR 和题目内容匹配方式，实现“导入 PDF → 框选屏幕区域 → 持续显示当前题目的答案”。

现支持逐人加载考试和“启动自动答题”：选择本机浏览器、导入人员信息，自动登录后停留在个人主页；手动进入考试并完成人员验证后，框选题目区域即可逐题核对和作答。存在未完成题目时不交卷，考试完成后保留浏览器。

Git 仓库提供源码、测试和构建脚本。首次克隆后，需要先安装 Python 3.11 或 3.12，运行 `安装依赖.cmd`，再运行 `启动软件.cmd`。题库 PDF、截图、个人运行数据、`runtime` 环境和打包文件不随源码仓库发布；题库请在软件内自行导入。

## 使用

### 免安装便携版

将 `NewXKY-portable.zip` 整包解压，双击其中的 `启动软件.cmd`。无需安装 Python，无需启动时下载 OCR 模型；题库自行导入。请保留 `runtime`、`assets`、`newxky` 等文件夹。

此便携版使用 Python 官网原始的签名运行程序。旧的 PyInstaller `dist/NewXKY/NewXKY.exe` 没有数字签名，可能被 Windows 智能应用控制阻止；便携版使用独立启动入口，不包含这个旧 exe。Windows 的信任判定以系统实际策略为准，项目不会修改安全功能。参考 [Microsoft Smart App Control 说明](https://learn.microsoft.com/en-us/windows/apps/develop/smart-app-control/overview)。

如启动失败，会显示提示并将详细错误写入 `data/startup-error.log`。也可以运行 `启动并查看错误.cmd` 查看错误信息。

开发者在 Windows 上执行 `python scripts/build_portable.py` 可构建便携 ZIP。构建过程验证 Python 官方下载文件的 SHA-256 和 Authenticode 签名，从 PyPI 安装依赖，并将本地 OCR 模型一起打包。`requirements-portable.txt` 对应新版 OCR 运行环境，常规源码安装仍使用 `requirements.txt`。

1. 安装依赖后双击 `启动软件.cmd`。如本机已有 `runtime` Python 运行环境则优先使用，其次使用 `.venv`，最后使用 `dist\NewXKY\NewXKY.exe`。
2. 点击“导入 PDF 题库”，选择题库文件，可以多选。导入在后台执行，进度显示当前文件及页码。有效题目、去重数量和异常会显示在界面；异常题目不会参与匹配。
3. 打开浏览器答题页，点击“框选 / 重选区域”，拖动选择**一道题的完整题干和全部选项**。Esc 或右键取消。
4. 把浏览器中的题目放在该区域内，并将答案窗口移到区域外。点击“开始识别”。绿色边框标出检测范围，不拦截鼠标。
5. 答案区显示正确答案字母、完整选项内容和 PDF 来源页码，优先按**当前网页选项顺序**显示。字母漏识别时，会结合完整选项内容和已识别字母的位置还原顺序；正确选项已有可核对的网页字母时直接采用。只有无法可靠对应时，才按**题库顺序**显示，并将这四个字标红。题目文字发生变化后，旧答案会先清空，再识别新题；鼠标悬停、边框及选项高亮的变化不清空答案。

可以暂停、重新识别、重选区域及开启窗口置顶。题库和上次选择的区域会自动保存，重新启动后无需重复导入。启动后不自动截屏，需要点击“开始识别”。

### 人员导入与逐人考试

1. 导入 PDF 题库。在“考试浏览器”下拉框选择浏览器；软件启动时会读取本机已安装浏览器，也可以点击“刷新列表”重新扫描或“浏览…”指定程序。支持 Chrome、Edge 及常见 Chromium 浏览器；不支持自动登录的浏览器会列出并置灰。此次选择只用于下一次加载，之前的窗口会保留。
2. 点击“导入人员信息…”，选择 Excel `.xlsx` 文件。工作表首行需要包含 **所在的区县、姓名、身份证号** 三列表头，顺序不限。身份证号请按文本保存；程序会跳过缺失、格式异常、精度已丢失及重复的记录，原因显示在运行记录中。导入人员只进入“备选人员”，不会自动进入待考队列。
3. 打开“备选 / 待考人员”页签，在左侧按姓名搜索，选中人员后点击“添加选中人员至待考 →”，或双击人员添加。可以按住 Ctrl / Shift 多选。右侧为“待考人员”，用鼠标拖拽调整从上到下的顺序，也可选中尚未开考的人员点击“移回备选人员”。
4. 点击“进行某某的考试”。按钮始终对应待考列表最上方的就绪人员，单击选中其他行不会改变考试顺序。软件为该人员打开独立的浏览器会话，进入对应区县，填写姓名和身份证号，识别登录验证码，**登录成功后停留在个人主页，不点击“进入考试”**。登录验证码自动识别三次仍未通过时，可以直接在浏览器中手动登录。
5. **本人在浏览器手动点击“进入考试”，按网页提示开考、完成人员验证并进入答题页面**，再点击“框选 / 重选区域”，包含完整题干、全部选项及底部翻页和交卷按钮。软件启动及加载人员时均默认选择“屏幕区域（鼠标兼容）”，点击“启动自动答题”开始逐题作答。
6. 确认交卷成功后，主界面自动恢复，该人员从待考列表移出，进度标为“已完成”，本次浏览器保持打开。重新选择需要使用的浏览器，点击“进行某某的考试”，才会加载待考列表新的首位人员。每次加载均使用独立会话，重新框选该浏览器的题目区域。

人员队列在本次软件运行期间保留，无需每人重复导入；姓名、区县、脱敏身份证号及状态可在“人员考试进度”中查看。完整人员表不写入题库和设置文件。暂停、缺题或交卷结果未确认时不会自动进入下一人；可以继续当前人员，或点击“跳过当前人员”后手动加载下一人。“停止加载”和关闭软件均保留已经打开的浏览器。

在“人员考试进度”中右键选中的人员，选择“添加到备选人员”，可将已完成、失败、暂停或跳过的人员移回备选，重新安排考试；支持多选。转回后重置该人员的本次完成状态，两份人员结果 Excel 同步更新。正在加载或自动答题时暂不能转回，暂停并等待后台任务完成后可操作。

每次导入会在 `data/人员结果/批次目录/` 自动创建 **已完成人员.xlsx** 和 **未完成人员.xlsx**，点击工作区右上角“结果文件夹”即可打开。两份文件均为“所在的区县、姓名、身份证号”三列，身份证号按完整文本保存，可直接重新导入。只有确认交卷成功的人员进入已完成文件；备选、待考、失败、暂停、跳过及转回备选的人员均属于未完成。人员完成或重置后自动更新，重新导入会创建新批次并保留此前结果。

若文件正在被 Excel 占用，软件会将最新的两份结果另存到本批次的“更新”目录，并将“结果文件夹”入口指向新目录；其他保存错误会显示“人员结果未保存”，可点击“重新保存”。

### 自动答题

**启动和继续都从当前题往后回答，不自动返回第一题。** 暂停后按钮变为“继续自动答题”，保留本次已完成和未完成记录；当前题已经选对时直接进入下一题。网页顺序与题库顺序不同时，按答案内容对应网页选项。

也可切换到“网页直连（不占鼠标）”：

1. 导入题库，点击软件中的“连接浏览器…”。按窗口说明，在 Chrome / Edge 扩展管理页加载随包的 `browser_extension` 目录。
2. 打开答题标签页，点击工具栏 NewXKY 扩展，将软件提供的连接码粘贴到扩展，点击“连接当前答题页”。连接码仅用于本机配对，不要分享给其他人。
3. 回到软件点击“启动自动答题”。直接读取并操作已连接标签页的题干、选项、选择状态及按钮，无需框选，不移动系统鼠标，也不要求浏览器保持前台。可继续使用鼠标键盘处理其他工作；按 **Esc** 或点击“暂停自动答题”暂停。
4. 遇到问题可以在页面处理后点击“继续自动答题”，从当前题继续；切换题目后原本尚未核验的题目会保留为未完成。

扩展只连接用户选择的一个答题标签页，使用 `activeTab`、`scripting` 和浏览器调试接口处理页面及原生交卷弹窗。浏览器可能显示调试提示；打开开发者工具或关闭目标标签页会断开连接。实现参考 [Chrome 官方 debugger API](https://developer.chrome.com/docs/extensions/reference/api/debugger)。

默认的“屏幕区域（鼠标兼容）”模式需要框入题干、选项以及底部“上一题 / 下一题 / 提交答卷”按钮；运行时浏览器需保持可见，程序会使用系统鼠标。移动窗口、遮挡区域、切换前台或手动操作会暂停。每题最多识别和滚动 30 秒、12 次滚动；无法可靠确认翻页结果时暂停，可点击继续重试。

两种模式均支持关键词检索、长题、已有选择核对和多选纠错。无可靠答案会记录并跳过，直到最后一题。存在未完成记录时**不提交答卷**；从中途开始时，还会核对网页整卷进度或“完成检查”的明确结果，确认前面的题也全部完成后才交卷。未知弹窗会暂停；未到交卷时间最多等待 10 分钟，缺少成功回执时不会重复提交。

当前通过原始截图缓存、文字布局缓存、字母裁剪缓存和重复文字行缓存减少推理；选中及按钮可用状态始终读取新截图。低置信度正文增加局部双重重读，否定词、数字和小数差异保留为不确定信息，不据此猜选。

单屏使用时可点击“悬浮答案”：主窗口最小化，小答案窗保持置顶，可拖到题目区外（例如页面上方的状态栏处）。点击“展开主界面”返回。悬浮窗也提供开始 / 暂停按钮。

点击“关键词查答案”（或按 `Ctrl+F`）可打开独立搜索窗口。输入题干或选项中的关键词，多个词用空格分隔；选择结果即可查看完整题目、正确选项全文及 PDF 来源页码。搜索答案明确按题库顺序显示，请按选项内容核对网页。无需框选或开启屏幕识别即可搜索；导入或清空题库后，搜索结果自动更新。

未完全匹配、但发现相似题时，答案区以红色“相似题参考”显示原题干、题库答案、完整正确选项及来源，供人工核对差异。相似题参考不会标为已核对的网页答案。

题干一致、但选项漏字或存在差异时，以红色“选项待核对”显示参考答案和题库原文。所有选项均能分别对应到唯一、明显更接近的题库选项时，参考字母按推测的网页顺序显示，并明确提示“参考网页顺序”；相近选项无法区分、内容重复或不够接近时，按标红的“题库顺序”显示。这类参考不会被标为已核对答案；请核对完整选项，尤其是否定词和数字。

## 题库格式

支持有文字层的 PDF，例如用户指定的《2026 年度法治理论知识考试复习资料》格式：

```text
1、题干内容（）
A. 选项甲
B. 选项乙
C. 选项丙
D. 选项丁
正确答案：B
```

支持跨页题目、单选、多选、判断、分章节重复题号、多份题库合并、重复题目去重。相同题干与选项存在不同正确答案时，整次导入失败，保留原题库。缺答案、选项异常等题目会跳过并记录原因。

当前不对扫描 PDF 整本做 OCR；扫描件需要先转换为带文字层的 PDF。无题号、无选项、答案集中在独立答案表、复杂分栏和其他格式需要另行适配。

## 识别范围与更新

- 使用本机 RapidOCR 中文模型，截屏不上传云端。普通识别只显示答案；“启动自动答题”按所选模式操作答题页面。只有点击加载人员时才会将当前人员的登录信息填写到考试网站。
- 网页必须在屏幕上可见。窗口遮挡、浏览器最小化、屏幕锁定或题目被截断都会影响识别。程序发现自己的答案窗口遮挡区域时会清除答案并提示调整。
- 每个区域位于单块显示器内，支持在多显示器环境中选一块屏幕，按 Qt 的逻辑坐标抓取原始分辨率图像。显示器布局变化后需重选区域。
- 默认每 100 毫秒检查画面中的文字笔画；文字稳定约 180 毫秒后在后台 OCR。原始截图相同时直接使用检测缓存；鼠标悬停带来的背景、边框、按钮及选项高亮、光标闪动会被过滤。此检测只决定是否重新识别，OCR 仍读取原始清晰截图。请避开题目区域以外持续变化的计时器文字。
- 题库加载后自动在后台预加载模型，CPU 根据可用核心数使用最多 4 个线程，长短文字逐行识别以减少无效填充计算。实际更新速度取决于区域大小、文字长度和 CPU。
- 完整题干和选项内容匹配时，优先按网页顺序重新对应字母。若正确选项已有明确字母，直接采用；完整内容和至少两个字母的位置一致时，可还原漏识别的字母。无法可靠对应时，显示题库字母及正确选项全文，并将“题库顺序”标红。全部选项已识别但内容与题库不一致时，以红色参考区显示答案、完整选项和核对提示；相似度只用于推测参考字母，不用于确认答案。相似题单独以红色参考区显示，未知题或答案歧义不显示确定答案。标点与排版空白统一处理，文字、否定词和数字保留。
- 只处理当前框内的一道题。可以只框选题干来获取题库答案；若需自动对应网页字母，请包含全部选项。长题可适当缩小浏览器比例后框选。
- 已适配独立 A/B/C/D 字母垂直居中、选项跨多行、选中状态的白字深色圆框和小字号字母。圆框内误读成“巴”等字的旧结果只在同一圆框内确认字母后替换，不删除正文中的同名字。题型标签和页内题号单独处理；长题干中的通用短题干不再被误判为第二道题。
- 字母漏识别或换行错位时，先通过实际字母与完整内容分析网页顺序；证据不足才回退为标红的“题库顺序”。相同题干的不同题目会结合全部选项区分；含糊或内容有差异时要求核对。
- 建议只框选题目卡片，包含完整题干和全部选项，不包含上方考生资料、计时器和答题卡。绿色上边框应位于题干上方；题干在框外时，程序不会读取框外文字。

## 开发运行

需要 Python 3.11 或 3.12、Windows 10/11。双击 `安装依赖.cmd`，或在项目目录执行：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe -m pytest -q
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

打包后的整个 `dist\NewXKY` 文件夹可以复制到其他 Windows 电脑。请勿只复制 exe；`_internal` 中包含 Qt、OCR 模型和运行库。

早期 PyInstaller 构建曾被本机 Windows 应用程序控制策略拦截，项目另有 Python 运行环境作为启动方式；最新 EXE 的验证结果见 `验证记录.md`。运行环境未提交到 Git 仓库。开发者可以在安装好依赖的 Windows Python 中执行 `python scripts/bundle_python.py` 生成 `runtime`，再连同 `newxky`、`main.py` 和启动脚本一起复制使用；无需依赖 Answering-S 目录或更改系统安全策略。

数据存放在程序旁的 `data\bank.json` 和 `data\settings.json`；源码运行时位于项目目录。请放在有写入权限的目录。`--data-dir` 可以指定其他存储目录。清空题库只清理缓存，不改动原 PDF。

主要模块：`bank.py` 解析和持久化，`matching.py` 内容核对和选项对应，`monitor.py` 画面版本及过期结果丢弃，`region.py` 框选，`ocr.py` 本地识别，`ui.py` 桌面界面和后台任务。

自动答题模块：`exam_view.py` 解析图像结构及按钮/选择状态，`automation.py` 管理检索和逐题流程，`auto_controller.py` 串行协调截图、后台 OCR 和输入，`desktop_input.py` 负责窗口绑定、缩放坐标及可取消的 Windows 输入。

人员模块：`browsers.py` 发现浏览器并创建独立会话，`identities.py` 导入 Excel 和管理逐人队列，`login_session.py` 与 `login_ocr.py` 处理登录，`personnel_controller.py` 在后台协调加载并停留主页，`personnel_results.py` 生成两份人员结果 Excel。浏览器使用本机安装的程序，无需另外下载 Playwright 浏览器。`tests/test_personnel_browser.py` 使用本地模拟网站和独立无头浏览器验证停留主页、手动开考后的答题交卷、切换浏览器及旧窗口保留，不访问真实考试服务。

`browser_bridge.py` 和 `browser_extension/` 提供带随机连接码及操作令牌的本机 WebSocket 通道；未连接或暂停后不能执行网页操作。`scripts/verify_browser_flow.py --chrome <Chrome路径>` 使用全新无头浏览器验证本地网页流程和配对通信，不连接用户现有浏览器资料，也不发送系统鼠标输入。

可使用 `python scripts/verify_automatic_flow.py` 运行完全离线的截图驱动集成验证；`--partial --long` 验证题干缺失和长题滚动，`--missing` 验证缺题时跳过且禁止交卷。这些测试只操作本地渲染器，不发送桌面输入。浏览器人工测试页面在 `tests/fixtures/automatic_exam.html`。

截图识别验证脚本接受自行提供的截图和题库缓存，例如：

```powershell
.\.venv\Scripts\python.exe scripts/verify_screenshots.py --bank data/bank.json --crop 60 410 1860 1253 --expect matched:B screenshot.png
```
