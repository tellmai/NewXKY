# NewXKY 网页直连（不占鼠标）

1. 启动 NewXKY，点击“连接浏览器…”，复制连接码。
2. 在 Chrome 打开扩展管理页（chrome://extensions），或在 Edge 打开扩展管理页（edge://extensions）。开启开发者模式，选择“加载已解压的扩展程序”，选择本目录。
3. 打开需要作答的标签页，点击工具栏的 NewXKY 扩展图标，粘贴连接码，点击“连接当前答题页”。
4. 软件选择“网页直连（不占鼠标）”，点击“启动自动答题”。从当前题开始，暂停后可继续；无需框选，也不移动系统鼠标。

仅连接您选择的答题标签页，不会读取其他标签页。浏览器可能显示“正在调试此浏览器”提示，这是处理页面及原生检查/交卷弹窗所需的接口。打开开发者工具、关闭目标页或退出软件会使连接断开。

连接码仅用于本机软件和扩展配对，请勿分享。若浏览器策略不允许加载扩展，可继续使用软件的“屏幕区域（鼠标兼容）”。
